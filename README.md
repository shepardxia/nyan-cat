# nyan-cat

A cat that wanders the desktop and now and then blows up. A widget for
[Rücksicht](https://github.com/shepardxia/ruecksicht).

```sh
rk add https://github.com/shepardxia/nyan-cat
```

Sprites are served under the folder's name, so the folder has to be called
`nyan-cat`, which `rk add` takes care of.
